# 🏐 Amigos do Vôlei League

Aplicação web para organizar as partidas de vôlei de areia de um grupo de amigos: presença, sorteio dos times, placar de sets, histórico e rankings. Feita para o celular, sem cadastro de usuário.

## Funcionalidades

- Montagem de rodadas e times, com sorteio equilibrado
- Placar de sets, com troca de times durante a rodada
- Histórico de rodadas e partidas
- Rankings do mês e de todos os tempos, mural dos campeões e fominha
- Votação para equilibrar os sorteios

## Tecnologias

Next.js, React, TypeScript, Tailwind CSS, Supabase e Vercel.

## Desenvolvimento

```bash
npm install
npm run dev
```

As variáveis de ambiente necessárias ficam fora do repositório.
